## Entry

> v8.2.1: fixed a bug where the nose itch would teleport 2cm to the left immediately upon receiving a scratch command from the hand.

## How it works

`main.py` writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating that it is 1–160 characters of non-whitespace UTF-8 text on a single line. The entry is deterministic: the same line on every run.

## Why this one

The field of 4,237 entries is flooded with 3am brain replays, bladder low-battery warnings, doorway amnesia, and "you too" auto-replies. The nose itch that relocates the instant the hand arrives is a specific, universal, wince-and-laugh body bug nobody in the field executed this way — "teleport 2cm to the left" plus "scratch command from the hand" keeps the dry engineering register all the way through. It beat the best eye-floater candidate 2–0 (margins 3+3) and the best floater-Zoom candidate 2–0 (margins 3+3) in position-reversed duels against the house judge model (z-ai/glm-5.3-flash) via `judge-call.py`.
